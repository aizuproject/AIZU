# Changelog

## 0.1.0 Beta — initial source release

The first public-source version. Earlier 0.2–0.4 numbers belonged to local development builds; this release establishes the public 0.1.x beta series.

- iPhone and iPad layouts for sharing apps and custom tasks through Discord Rich Presence.
- App Store search, custom names and descriptions, local artwork and public image URLs.
- Share/start/stop controls, elapsed time, delivery status and retry behavior.
- App URL and Shortcuts launch after a successful activity update.
- Shortcuts actions for activity start, stop and the sharing switch.
- Silent-audio background connection lifetime, with explicit force-quit and interruption limits.
- Korean, English, Japanese and Simplified Chinese UI with automatic or manual language selection.
- Reproducible SDK-free preview builds, simulator tests, iPad documentation media and contributor/security policies.

This is a source release for personal builds, not an App Store release. Real-device battery use and long-duration reliability remain open validation work.
